Evidence-Tracked Pathway Map Prompt

A prompt template that asks a general-purpose LLM to build a biological pathway map from the literature — and to leave behind the evidence trail that produced it.

Template (English) Template (日本語) Method notes Worked example

The output is two files that stay in sync: a GPML file (GPML2013a) that opens and edits natively in PathVisio, and an Excel workbook in which every node and every edge traces back to a specific observation in a specific paper. GraphIds in the GPML match row IDs in the workbook, in both directions.

What problem it addresses

Asking a model for “a pathway diagram of X” usually produces one of two failure modes: a picture pasted into a file that cannot be edited, or a plausible-looking network in which it is impossible to tell which arrows rest on a direct biochemical experiment, which rest on a knockdown, and which rest on a correlation observed in a different cell type.

Two gradings, not one score

Directness (E1–E4) and context fit (C1–C4) are recorded separately. A binding assay in the wrong cell type and an indirect effect in the right model are different weaknesses.

Grammar tied to evidence

Arrowhead shape encodes the action. Line style encodes the pathway layer. Anything resting on association alone is drawn broken, and the legend says so.

Gaps stay visible

Where evidence is absent, the template requires Mediator unresolved rather than a plausible filler. Empty searches are recorded as empty searches.

The grading scheme

Evidence levelMeaning
E1Direct — purified protein / in vitro reaction, direct binding, ChIP + reporter mutation
E2Perturbation-dependent — knockdown, knockout, inhibitor or overexpression changes the readout
E3Indirect — perturbation effect shown, but a mediator may intervene
E4Association only — correlation, co-expression, co-localisation
Context fitMeaning
C1Species, disease, cell/tissue and condition all match
C2Species matches; cell, disease or condition partly differs
C3Different species, or an unrelated cell line
C4Cell-free, computational prediction, or database annotation only

A relation enters the main pathway only if it is C1–C2 and carries at least one piece of E1–E3 evidence. Everything else is a drawn-but-broken candidate pathway, or held-back information with the reason recorded. Full rationale in the method notes.

Worked example: NRF2 in colorectal cancer

Every route found for raising NRF2 level or activity in colorectal cancer turned out to be post-transcriptional: GDF15–AKT–GSK3β stabilisation (with NRF2 driving GDF15 in return, closing a feedback loop), UCKL1 stabilisation, HNRNPC acting on both transcript and protein, and CHTOP recruiting a SENP3 complex that deSUMOylates NRF2. The one negative regulator retrieved with direct promoter-binding evidence is FOXO3 → KEAP1.

The example is included partly because it did not come out clean:

  • Two of the five requested phenotypes — anoikis resistance and stemness — had no colorectal-cancer evidence at all. Both are drawn as broken candidate arms labelled Mediator unresolved.
  • One retrieved paper was retracted, and is recorded as excluded rather than silently dropped.
  • One relation has directly conflicting evidence. Both findings are recorded, along with which was adopted and why.
  • Three relations were downgraded to candidate because the only support was a review article or an association.
Caveat. All 12 papers in the example were read as PubMed abstracts only; no figure panel was opened. Every observation row is marked confirm = abstract. The four relations graded E1 should be checked against the original figures before the map is used for anything load-bearing.

Format-validated is not rendering-confirmed. The GPML passes xmllint --noout --schema GPML2013a.xsd, and the previews are rendered from the same structural definition — but by a separate renderer, not by PathVisio. Details may differ from how PathVisio lays the file out.

Scope and limits

  • Produces a baseline map: no drug-intervention layer. Overlaying compounds is a separate pass.
  • Does not verify biology. It records what the retrieved papers state, with the grading applied, and makes the reasoning auditable — a different thing from being right.
  • Grading is applied by a language model and is not reproducible run to run. Read E/C values as documented reasoning to be checked, not as measurements.
  • Evidence quality is bounded by what the model could read. Abstract-only runs are a starting point for manual verification.
